# SmartFridge Backend

This repository contains the backend for the SmartFridge project.

This repository is a fork of the original backend created by Iris-F for the
TechLabs Amsterdam SmartFridge project.

Original repository:
https://github.com/Iris-F/smart-fridge

## Purpose

The backend provides server-side functionality including:

- Authentication
- Product management
- Database communication
- API functionality

## Frontend Integration

This backend communicates with a separate Vanilla JavaScript frontend.

Frontend repository:

https://github.com/pris1/smartfridge-frontend
